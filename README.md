## Датасет

Выбран датасет [Obesity Levels](https://www.kaggle.com/datasets/fatemehmehrparvar/obesity-levels) для многоклассовой классификации уровня ожирения. В нем 7 классов, более 2000 наблюдений, числовые и категориальные признаки.

Датасет лежит в каталоге `data/`. EDA выполнен в `EDA.ipynb`, проверка гипотез и обучение моделей -- в `research.ipynb`.

## Проверяемые гипотезы

Для гипотез 1, 2 и 5 используется стратифицированная кросс-валидация на 5 фолдах с одинаковыми разбиениями. Основная метрика -- `macro-F1`, дополнительная -- `accuracy`.

В гипотезах 3 и 4 данные разделены на train, validation и test: важности рассчитываются на validation, а качество выбранных признаков проверяется на test. В гипотезе 7 границы выбросов рассчитываются только по train, test не изменяется.

### 1. Рост и вес содержат достаточно информации для классификации

KNN на стандартизированных признаках `Height` и `Weight` сравнивается с KNN на всех исходных признаках.

> **Вывод:** гипотеза подтвердилась. `Height` и `Weight` дали `macro-F1 = 0.949` и `accuracy = 0.951`, все признаки -- `0.800` и `0.824`.

### 2. Добавление признаков `BMI` и `Weight / Height` повысит качество

К исходным признакам последовательно добавляются `BMI = Weight / Height²` и `Weight / Height`.

> **Вывод:** гипотеза подтвердилась. `BMI` повысил `macro-F1` с `0.800` до `0.835`, а добавление обоих признаков -- до `0.857`. `Accuracy` выросла с `0.824` до `0.872`.

### 3. `Weight`, `Height` и `BMI` окажутся наиболее важными признаками

Permutation importance рассчитывается для дерева решений на отдельной validation-выборке.

> **Вывод:** гипотеза подтвердилась частично. `BMI` и `Weight` вошли в тройку наиболее важных признаков, однако `Height` не попал в топ-10 на выбранной validation-выборке.

### 4. Пяти лучших признаков будет достаточно для сохранения качества

Пять лучших признаков выбираются по permutation importance на validation. Затем KNN на них сравнивается с KNN на полном наборе с `BMI` на отдельной test-выборке.

> **Вывод:** гипотеза подтвердилась. Топ-5 повысил `macro-F1` с `0.834` до `0.951`, `accuracy` -- с `0.852` до `0.952`.

### 5. Удаление почти константных признаков не ухудшит качество

Из набора удаляются `SMOKE` и `SCC`, у которых одна категория преобладает более чем в 90% наблюдений.

> **Вывод:** заметного эффекта нет. `macro-F1` изменился с `0.800` до `0.802`, `accuracy` -- с `0.824` до `0.825`.

### 6. Регуляризация не даст существенного прироста

Сравниваются три конкретные конфигурации `LogisticRegression` с solver `saga`: практически без регуляризации (`C = 1e6`), L1 (`C = 1`) и L2 (`C = 1`).

> **Вывод:** для проверенных конфигураций L1 почти не изменила качество: `macro-F1` снизился с `0.9612` до `0.9608`. L2 дала `0.8813`. Общий вывод о типе регуляризации делать рано, поскольку сила штрафа отдельно не подбиралась.

### 7. Сохранение потенциальных выбросов даст лучшее качество, чем их удаление

Границы IQR для `Age`, `Height` и `Weight` рассчитываются только по train. Найденные выбросы удаляются только из train, test остается неизменным.

> **Вывод:** гипотеза подтвердилась. После удаления 118 объектов из train `macro-F1` снизился с `0.788` до `0.753`, `accuracy` -- с `0.814` до `0.774`.
