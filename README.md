## Проверяемые Гипотезы

Для проверки гипотез буду использовать кросс-валидацию. Основная метрика -- `macro-F1`, также буду считать `accuracy` (сильного дисбаланса классов нет, норм). 

### 1. Рост и вес формируют естественную структуру классов

В пространстве признаков `Height` и `Weight` наблюдения образуют группы, частично соответствующие уровням ожирения. Кластеризация стандартизированных значений роста и веса  должна показать статистически значимое соответствие целевой переменной.
