## Задача

Нужно предсказать вероятность того, что владелец автомобильной страховки подаст заявление о страховом случае в течение следующего года.

Бинарная классификация:

- `target = 1` -- страховой случай произошел;
- `target = 0` -- страхового случая не было.

Метрика -- **Normalized Gini Coefficient**:

```text
Gini = 2 * ROC-AUC - 1
````

Метрика оценивает качество ранжирования объектов: реальные положительные объекты должны получать более высокие предсказания.

## Данные

Данные анонимизированы. Из названия признака известны только его группа и тип:

* `ind` -- признаки клиента;
* `reg` -- региональные признаки;
* `car` -- признаки автомобиля;
* `calc` -- расчетные признаки;
* `_bin` -- бинарные признаки;
* `_cat` -- категориальные признаки.

Значение `-1` обозначает пропуск.

Размеры данных:

* `train` -- 595 212 объектов;
* `test` -- 892 816 объектов;
* 57 признаков без учета `id` и `target`.

## Что сделано

### EDA

Проверил:

* размеры и типы данных;
* баланс классов;
* пропуски;
* распределения признаков;
* выбросы и диапазоны значений;
* различия между классами;
* различия между `train` и `test`;
* корреляции;
* дубликаты.

Основные выводы:

* положительный класс встречается редко;
* распределения классов сильно пересекаются;
* явного сдвига между `train` и `test` нет;
* большинство признаков слабо коррелируют;
* пропуски могут сами содержать полезный сигнал;
* отдельные признаки слабые, поэтому важны их комбинации.

Ноутбук: [`00_EDA.ipynb`](./00_EDA.ipynb).

### Feature Engineering

Для быстрого сравнения преобразований использовал `GaussianNB` без подбора гиперпараметров.

Все преобразования обучаются внутри CV-пайплайна, чтобы не было утечек.

Проверил:

* исходный набор признаков;
* удаление почти константных признаков;
* удаление равномерно распределенных признаков;
* заполнение числовых пропусков медианой;
* добавление флагов пропусков;
* One-Hot Encoding категориальных признаков;
* масштабирование и PCA с разным числом компонент.

Лучший результат на CV дал `PCA` с двумя компонентами:

```text
Normalized Gini: 0.190694
```

Что сработало:

* `PCA(n_components=2)` заметно улучшил результат;
* медиана с флагами пропусков дала небольшой прирост;
* аккуратное удаление только совсем константных признаков не ухудшило качество.

Что не сработало:

* агрессивное удаление почти константных признаков сильно ухудшило результат;
* удаление равномерных признаков почти ничего не изменило;
* увеличение числа PCA-компонент не гарантировало улучшения;
* логарифмы не использовал: больших хвостов в числовых распределениях нет.

Ноутбук: [`01_feature_engineering.ipynb`](./01_feature_engineering.ipynb).
