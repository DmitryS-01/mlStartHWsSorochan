## Проверяемые гипотезы

Для гипотез 1, 2, 4, 5 и 6 используется стратифицированная кросс-валидация на 5 фолдах с одинаковыми разбиениями. Основная метрика -- `macro-F1`, дополнительная -- `accuracy`.

В гипотезе 3 важности признаков считаются на отложенной выборке размером 25%. В гипотезе 7 используется отдельное стратифицированное разбиение на train и test в отношении 75/25.

### 1. Рост и вес содержат достаточно информации для классификации

KNN-классификатор на стандартизированных признаках `Height` и `Weight` должен показать качество не ниже KNN на всех исходных признаках.

> **Вывод:** гипотеза подтвердилась. `Height` и `Weight` дали `macro-F1 = 0.949` и `accuracy = 0.951`, все признаки -- `0.800` и `0.824`.

### 2. Добавление признаков `BMI` и `Weight / Height` повысит качество классификации

К исходным признакам последовательно добавляются `BMI = Weight / Height²` и `Weight / Height`. Ожидается, что они улучшат качество KNN.

> **Вывод:** гипотеза подтвердилась. `BMI` повысил `macro-F1` с `0.800` до `0.835`, а добавление обоих признаков -- до `0.857`.

### 3. `Weight`, `Height` и `BMI` окажутся наиболее важными признаками

Permutation importance рассчитывается для дерева решений на отложенной выборке. Ожидается, что антропометрические признаки займут верхние позиции.

> **Вывод:** гипотеза подтвердилась частично. `BMI` и `Weight` заняли первые два места, но `Height` оказался шестым. В топ-5 также вошли `Gender`, `TUE` и `Age`.

### 4. Пяти лучших признаков будет достаточно для сохранения качества

Пять лучших признаков выбираются по permutation importance из предыдущего эксперимента. Затем KNN на них сравнивается с KNN на полном наборе с добавленным `BMI`.

> **Вывод:** гипотеза подтвердилась. Топ-5 повысил `macro-F1` с `0.835` до `0.913`. Результат может быть оптимистичным, поскольку признаки выбраны до кросс-валидации.

### 5. Удаление почти константных признаков не ухудшит или немного повысит качество

Из набора удаляются `SMOKE` и `SCC`, у которых одна категория преобладает более чем в 90% наблюдений.

> **Вывод:** эффект практически отсутствует. `macro-F1` вырос с `0.800` до `0.802`, `accuracy` -- с `0.824` до `0.825`.

### 6. Смена типа регуляризации не даст существенного прироста линейной модели

Сравниваются логистическая регрессия с параметрами по умолчанию, логистическая регрессия с L1-регуляризацией и `RidgeClassifier`. Для логистических моделей увеличено только число итераций, чтобы обучение сходилось без предупреждений.

> **Вывод:** гипотеза не подтвердилась. При числе обусловленности `2.22` L1 повысила `macro-F1` с `0.881` до `0.961`, а `RidgeClassifier` снизил его до `0.600`.

### 7. Сохранение потенциальных выбросов даст лучшее качество, чем их удаление

Границы IQR для `Age`, `Height` и `Weight` рассчитываются только по train. Найденные выбросы удаляются только из train, test остаётся неизменным.

> **Вывод:** гипотеза подтвердилась. После удаления 118 объектов из train `macro-F1` снизился с `0.788` до `0.753`, `accuracy` -- с `0.814` до `0.774`.
