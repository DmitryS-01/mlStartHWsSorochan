# ML Start hw02 -- Porto Seguro’s Safe Driver Prediction

> Сорочан Дмитрий @legenda0008

Соревнование: [Porto Seguro’s Safe Driver Prediction](https://www.kaggle.com/competitions/porto-seguro-safe-driver-prediction)

## Задача

Нужно предсказать вероятность того, что владелец автомобильной страховки подаст страховое заявление в течение следующего года.

Задача бинарной классификации:

* `target = 1` — страховой случай произошел;
* `target = 0` — страхового случая не было.

Основная метрика соревнования — **Normalized Gini Coefficient**.

## Данные

Данные анонимизированы. Названия признаков показывают только их группу и тип:

* `ind` — признаки, связанные с клиентом;
* `reg` — региональные признаки;
* `car` — признаки автомобиля;
* `calc` — расчетные признаки;
* `_bin` — бинарные признаки;
* `_cat` — категориальные признаки;
* остальные признаки являются числовыми или порядковыми.

Значение `-1` означает пропуск.

Размеры выборок:

* `train` — 595 212 объектов;
* `test` — 892 816 объектов;
* 57 признаков без учета `id` и `target`.

## EDA

Проведен базовый анализ данных:

* проверены размеры и типы данных;
* исследован баланс классов;
* отдельно рассмотрены бинарные, категориальные и числовые признаки;
* проверены пропуски, закодированные значением `-1`;
* исследованы выбросы и диапазоны значений;
* построены распределения признаков;
* сравнены распределения классов `0` и `1`;
* сравнены распределения `train` и `test`;
* проверены корреляции между признаками;
* проверены дубликаты.

Основные выводы:

* классы сильно несбалансированы, положительных объектов мало;
* распределения большинства признаков для классов `0` и `1` визуально очень похожи;
* сильного сдвига между `train` и `test` не найдено;
* большинство признаков слабо коррелируют между собой;
* часть признаков содержит заметное количество значений `-1`;
* отдельные признаки сами по себе дают слабый сигнал, поэтому основной результат, скорее всего, будет получен за счет их комбинаций.

EDA находится в ноутбуке [`EDA.ipynb`](EDA.ipynb).

## Скачивание данных

Сначала нужно принять правила соревнования на Kaggle.

Затем создать API-токен в настройках аккаунта Kaggle и положить файл `kaggle.json` в папку:

```bash
mkdir -p ~/.kaggle
mv ~/Downloads/kaggle.json ~/.kaggle/kaggle.json
chmod 600 ~/.kaggle/kaggle.json
```

После этого из корня проекта выполнить:

```bash
python3 data/download_data.py
```

Скрипт автоматически:

* скачает архив соревнования;
* распакует его в папку `data`;
* удалит архив;
* проверит наличие нужных CSV-файлов.
